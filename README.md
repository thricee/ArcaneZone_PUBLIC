
# ArkaneZone - Roblox Swordfighting Anticheat
✅ Now as an open-sourced project!

ArkaneZone is an anticheat system designed to prevent players from gaining an unfair advantages using external programmes in Roblox Swordfighting. This system uses a bare-bones ping-based networking system that is designed to be invisible to penetration testing tools.

However, due to frequent updates to the Roblox Engine; The functions and methods used in this system seem to be deprecated. That now is up-to you to fix. Have fun learning using this code as this system had given me plenty of experience and knowledge regarding the Luau environment.
